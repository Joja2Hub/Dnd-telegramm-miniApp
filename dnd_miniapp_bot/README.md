# DND Mini App

Telegram-бот, локальный сайт и хаб игроков для настольных кампаний.

## Быстрый запуск

Дважды нажми **START_LOCAL_SITE.bat** прямо в этой папке. Такой же ярлык
запуска есть на уровень выше, в папке `DND BOT`.

Оставь окно сервера открытым на время игры. Локальный адрес:
`http://127.0.0.1:8000/local/`. Ссылку для игроков в той же Wi-Fi-сети смотри
в `local_host/SERVER_ADDRESS.txt` после запуска: `localhost` на телефонах
игроков не подходит.

Вход: пользователь → личный профиль → игры, персонажи, достижения, магазин
и инвентарь аккаунта. Мастер делает свою игру активной из её настроек.

## Другие режимы

- `START_PUBLIC_SERVER.bat` — запуск Telegram-бота и публичного Mini App.
- `START_BOT_CLOUDFLARE.bat` — альтернативный запуск с обходом конфликтов VPN.
- `STOP_BOT_AND_SEND_SUMMARY.bat` — остановка бота и итог сессии.
- `run.bat` / `run.sh` — установка окружения и обычный запуск через Python.
- `Dockerfile` / `docker-compose.yml` — запуск в контейнере.

Локальный и публичный серверы используют одну базу и один порт. Одновременно
запускай только один режим. Локальный выбор пользователя не является защищённым
входом и подходит только для доверенной сети.

## Структура проекта

| Папка | Содержимое |
|---|---|
| `app/` | Backend, Telegram-бот, правила, данные и сервисы |
| `frontend/` | Общий интерфейс Mini App и используемые графические ресурсы |
| `local_host/` | Локальный вход, хаб, профили и сервер локальной игры |
| `public_host/` | Запуск публичного сервера |
| `data/` | Рабочая база, загрузки игроков и резервные копии |
| `data/backups/manual/` | Резервные копии перед обслуживанием и изменением данных |
| `references/characters/` | Исходные референсы персонажей |
| `archive/` | Проверенные архивы старых данных и промежуточных исходников |
| `docs/` | Инструкции, архитектура и отчёт о чистке |
| `output/` | Актуальные подготовленные материалы, включая каталог наград |
| `tests/` | Автоматические проверки |
| `tools/` | Генерация каталогов, обслуживание и проверка данных |
| `logs/` | Журналы запусков |
| `tmp/` | Временные результаты тестов; не используется для хранения игры |

`.env` содержит настройки и секреты. `.venv` содержит установленное окружение.
Не удаляй `data/`, `.env` и `.venv` при обычной чистке.

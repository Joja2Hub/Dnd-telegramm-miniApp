# Служебные инструменты

- `sync_effect_catalog.cjs` — обновляет общий JSON-каталог эффектов из стенда.
- `export_treasury_catalog.py` — пересоздаёт полный каталог наград в `output/`.
- `upgrade_effect_shop.py` — резервная копия базы, обновление схемы и проверка целостности.
- `create_red_dragon_campaign.py` — проверенный импорт кампании из четырёх PDF;
  без `--apply` только показывает план, повторное создание блокируется.
- `polish_red_dragon_inventory.py` — разовое обслуживание описаний и эмодзи
  предметов этой кампании. Другие игры не затрагивает.
- `clean_project.ps1` — план файловой чистки без изменений по умолчанию.
  `-Apply` применяет план: уникальные данные сначала архивируются и проверяются
  по SHA-256. Существующий архив не перезаписывается. Не удаляет рабочую базу.

Все Python-скрипты запускаются из установленного окружения проекта.
Резервные копии обслуживания находятся в `data/backups/manual/`.
